## Xiaomi-pad7-dev

This organization contains the repositories required to build LineageOS-based ROMs for the Xiaomi Pad 7 (uke), based on the Qualcomm Snapdragon 7+ Gen 3 (SM7675) platform.

**Maintainer:** [Thanick50](https://github.com/Thanick50)

**Status:** Currently supports LineageOS 24.0 (Android 17)

**Bug:** USB-c dp alt mode
